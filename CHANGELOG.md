# Hardware development history

English | [简体中文](CHANGELOG.zh-CN.md)

The design used `v0.x` names first and `V0xx` names later. The table below lists the design changes between revisions.

| Period | Revision | Change |
|---|---|---|
| 2026-09-06 | Concept–v0.5 | Eight-page schematic, component selection and initial footprint checks |
| 2026-09-06–07 | v0.6–v0.10 | First routed boards, layout rework and mechanical studies |
| 2026-09-07 | v0.11–v0.12 | USB routing/protection branches, widths and reference-ground review |
| 2026-09-07 | v0.13–v0.14 | Isolation mount study and silkscreen/mask corrections |
| 2026-09-08 | v0.15 | Six horizontal PWB connectors; J4 reduced to five contacts; optional receiver/GNSS |
| 2026-09-09–10 | V016 R2 | Netlist synchronization, placement and return-path corrections, 45 test points, assembly-output checks and branding orientation fixes |
| Confirmed 2026-09-11 | Manufacturing | Owner confirmed submission; final order attachments and parameters pending |

The v0.13 mechanical models and early schematic PDF predate the current connectors. Use the [hardware downloads](docs/releases.md) for this prototype.
