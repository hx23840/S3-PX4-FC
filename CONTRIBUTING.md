# Contributing

English | [简体中文](CONTRIBUTING.zh-CN.md)

For a hardware issue, identify the release and affected component or pin, then describe the expected and observed behavior. Include measurements or images where useful.

For a hardware change, start from that release's `.epro2` in EasyEDA. Describe the circuit or mechanical changes and their checks in the pull request; provide the revised project and outputs as downloadable attachments. The Git diff contains the accompanying documentation or reusable code changes.

Update English and Simplified Chinese reader documentation together. Keep `AGENTS.md` in English only. Run the [repository checks](scripts/README.md) before submitting. See [publishing a version](docs/releasing.md) for release handling and [LICENSE](LICENSE.md) for the hardware/code/documentation terms. Identify third-party sources and remove personal information from attachments.
