# 发布硬件版本

[English](releasing.md) | 简体中文

EDA 工程历史记录电路修改，Git 记录仓库文档和通用代码修改。GitHub Release 分发明确硬件版本的工程快照及配套输出。

1. 在 EDA 中确定硬件版本，从该设计导出 `.epro2`、Gerber、BOM、贴装坐标和相关图纸。
2. 将导出文件放在 Git 工作目录之外的版本文件夹，文档和可复用工具在 Git 中维护。核对导出文件，并重新导入 `.epro2`。
3. 在 Git 中更新开发记录和下载索引，核对中英文文档，运行 `python3 scripts/check_repository.py`。
4. 为审查后的文档及代码打上对应硬件版本的 Git 标签，创建同名 GitHub Release，分别上传工程、Gerber、BOM、贴装坐标和校验文件。Gerber 各层保留制造 ZIP 格式，不制作混合工程与文档的总包。
5. 发布说明写明电路改动、测试和制造状态，将发布地址补入下载索引。

保留已发布版本的附件。工程或制造文件改变时，使用新版本及 Release。账号及订单个人信息不进入公开附件。
